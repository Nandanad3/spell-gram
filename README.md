# ✨ Spell-Gram

A Python-based tool that helps users detect spelling mistakes and grammar issues in text. Spell-Gram provides correction suggestions and can be used as a standalone desktop application or integrated into other Python workflows.

---

## 📖 Overview

Spell-Gram is designed to improve writing accuracy by identifying spelling and grammatical errors in user-provided text. The application works offline and offers an easy-to-use interface for checking and correcting text efficiently.

---

## 🚀 Features

- ✅ Spell checking of input text
- ✅ Grammar correction suggestions
- ✅ Desktop application interface
- ✅ Offline functionality
- ✅ Easy integration into other Python projects and workflows
- ✅ Simple and user-friendly design

---

## 🛠️ Technologies Used

- Python
- Tkinter (GUI)
- LanguageTool / Grammar Checking Library
- PySpellChecker

---

## 📦 Getting Started

### Prerequisites

Make sure you have the following installed:

- Python 3.x
- pip

---

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/Nandanad3/spell-gram.git
```

### Navigate to the Project Directory

```bash
cd spell-gram
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Running the Application

Run the following command:

```bash
python app.py
```

or

```bash
python main.py
```

(Use the file that serves as the project's entry point.)

## 💡 Usage

1. Launch the application.
2. Enter or paste the text to be checked.
3. Click the **Check** button.
4. Review spelling and grammar suggestions.
5. Apply corrections as needed.
